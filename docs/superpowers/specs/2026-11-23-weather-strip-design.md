# 日期天气带（鹰潭）— 设计

日期：2026-11-23
状态：待确认

## 1. 意图

点某一天时，除了鱼情，还能马上看到这一天的鹰潭天气：天气现象、最高/最低温、风、降水概率、湿度。切换日期时天气跟着变，不需要再去别处查天气。

## 2. 已确认

- 位置：**顶部设置卡 `#pick` 的右侧**（用户 2026-11-23 澄清，覆盖最初“日期详情顶部”方案）。设置卡原来右侧空着，天气放这里正好填满。
- 使用当前钓点同一份 Open-Meteo 预报（鹰潭范围内），不新增接口、不额外请求。
- 只做展示，不改评分、不改 v0.5/v0.6 公式。
- 默认点/鹰潭城市不是这次要拆分的对象；天气带标题统一写“鹰潭”。
- 用户不用英文版，本次不做英文验收；只保留最小动态键，避免英文页缺字段/构建失败。

## 3. 方案对比

- **A 日期详情顶部**：天气和主钓/排行在同一视线范围；但设置卡右侧会一直空着。
- **B 7 天卡片内**：一眼看全 7 天，但 375px 下卡片已经拥挤，天气图标/高低温会抢分数。
- **C 顶部设置卡（选）**：把原本空着的右侧填满，打开页面就看到；点下方日期后天气会更新，但需要向上看。

A/B 不选。

## 4. 页面结构

在 `#pick` 的 `.opts` 里加第二列：

```text
当前按信江（鹰潭段）出预报；4 种目标鱼固定参与排序，可切换水域类型。
┌ 设置卡 ─────────────────────────────────────────────┐
│ 水域类型                天气                         │
│ [河流 / 运河]         鹰潭 · 今天 11/23              │
│                       🌧️ 雨  12–14.1℃               │
│                       东风 2级 · 降水 100% · 湿度 91%│
└──────────────────────────────────────────────────────┘
已手动选「河流 / 运河」。
```

- 桌面 `.opts` 两列：左水域类型，右天气；窄屏一列，天气在水域下方。
- 天气带用中性浅底（`--line-soft`），不用品牌色。
- 图标先用 emoji（晴/多云/阴/雾/雨/雪/雷雨），不新增图片依赖；以后要统一可换内联 SVG。
- 天气带标题固定“天气”，内容第一行是“鹰潭 · 今天/明天/周X 日期”，随选中日期更新。
- 详情原来的 `#d-meta` 去掉“气温 12–14.1℃”（移到天气带），保留估算水温、降水量、日出日落、月出月落；降水概率和降水量是两个不同信息，都保留。

## 5. 数据与计算

### 5.1 来源

- `S.fc.hourly` 和 `S.fc.daily`，当前钓点已有数据；日期用 `S.days[S.sel].date`。
- 不新增 fetch，不新增 API；天气和鱼种无关。
- 白天窗口：`06:00 ≤ h < 18:00`；没有白天小时则退回当天全部可用小时。

### 5.2 汇总字段

新增纯函数模块 `web/weather.js`：

```js
summarizeDay(fc, date) -> {
  code,       // 原始 WMO code
  kind,       // clear|mainlyClear|partlyCloudy|overcast|fog|drizzle|rain|heavyRain|snow|thunder|unknown
  tempMax, tempMin,
  windSpeed,  // m/s，白天最大
  windDir,    // 0–7，白天最大风速那一小时的方向
  windLevel,  // 0–12，蒲福风级
  rainProb,   // 白天最大降水概率 %
  humidity,   // 白天平均相对湿度 %
} | null
```

- 天气现象：按白天出现过的最高严重度取，避免“中午下雨但显示晴”。顺序：
  `thunder (95–99) > heavyRain (65/67/82) > rain (61/63/66/80/81) > snow (71–77/85/86) > drizzle (51–57) > fog (45/48) > overcast (3) > partlyCloudy (2) > mainlyClear (1) > clear (0)`。
- 温度：优先 `daily.temperature_2m_max/min`；缺失时用白天 hourly 的最高/最低。
- 风：白天最大 `wind_speed_10m` 及该小时 `wind_direction_10m`；按 8 方位映射，m/s 转蒲福风级。
- 降水概率：白天 `precipitation_probability` 最大值；缺失显示 `—`。
- 湿度：白天 `relative_humidity_2m` 非空值平均，四舍五入；缺失显示 `—`。
- 缺字段不要整块消失：单项显示 `—`；整日没有可用数据才隐藏天气带。
- `summarizeDay` 不碰 DOM，不 import 浏览器 API。

### 5.3 显示文案

动态文案放 `app.js` 的 `TXT`：

- 天气现象：晴 / 晴间多云 / 多云 / 阴 / 雾 / 毛毛雨 / 雨 / 大雨 / 雪 / 雷雨 / —
- 八方位：北 / 东北 / 东 / 东南 / 南 / 西南 / 西 / 西北
- 风：`北风 3级`；英文 `N wind, force 3`
- 降水概率：`降水 20%`；英文 `20% rain`
- 湿度：`湿度 68%`；英文 `68% humidity`
- 温度：`12–18℃`；英文 `12–18°C`

## 6. 边界

- 天气接口失败/空 days：沿用现有错误/空态，`#d-weather` 不显示，不出现无限 loading。
- 某字段 null：显示 `—`，不隐藏整条天气带。
- 切换日期：`renderDetail` 用新日期重算天气，不发新请求；主钓/排行逻辑不变。
- 375px：天气带自动换行，不横向滚动。
- 英文页：天气文案全英文；地点名“鹰潭”可保留中文地名或显示 Yingtan，按现有动态地名规则处理。
- 改 `#pick` 的 `.opts` 为两列（水域类型 + 天气）；不改 7 天卡片。
