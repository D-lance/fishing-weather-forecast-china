# 每日多鱼种主钓建议（固定全选）— 设计

日期：2026-11-23
状态：已确认（2026-11-23 简化为固定全选 4 种，不再做鱼种勾选）
后续变更（2026-11-23）：点排行鱼种时 `#d-best`/详情头部也跟随查看鱼种；第一名仍保留“主钓”徽标。

## 1. 意图

出发前直接看：**今天主钓哪一种**、其他目标鱼的备选排行，以及当前查看鱼种的八项分、曲线、建议、安全提示和 v0.6 影子分。

不做鱼种勾选：4 种目标鱼始终全部参与排序。点某一天，详情直接回答“这天主钓哪种、备选怎么排”。

## 2. 鱼种范围

鹰潭模式固定 **4 种目标鱼**，全部参与排序：

| key | 名称 | 参与排序 |
|---|---|---|
| crucian | 鲫鱼 | 始终 |
| bream | 鳊鱼 | 始终 |
| culter | 翘嘴/鲌鱼 | 始终 |
| mandarin | 鳜鱼 | 始终 |

- 海鲈、黑鲷、罗非、鲈鱼、黑鱼、鲢鳙、黄颡鱼不放进鹰潭模式；引擎表保留，供以后其他模式使用。
- 台钓建议：非路亚鱼种给粉饵；翘嘴/鳜鱼等路亚鱼种给虾肉/虾饵优先。只改建议文案判断，不改评分公式。

## 3. 目标

- 页面不再显示鱼种勾选控件；4 种目标鱼固定全选、固定排序。
- 7 天卡片显示每天**这 4 种里最高分**，并标出鱼种名。
- 点某天，详情顶部显示“主钓：X（分数/等级/最佳时段/水层/饵料）”。
- 主钓下面列出 4 种的备选排行（分数、等级、最佳时段）；默认前 3 名，可“展开全部”。
- 点排行里的鱼种，切换下方八项分/曲线/建议/影子分的查看对象；主钓不变。
- URL 不再写 `sp`；旧的 `sp=` 链接照常打开，但忽略鱼种参数，统一按 4 种排序。
- **不改评分模型**：线上仍是 v0.5；v0.6 影子只跟随当前查看鱼种，不参与主分。
- 保留安全封顶、溶氧提示、水域上下文权重。

## 4. 非目标

- 不做鱼种勾选、筛选、自定义鱼种集合。
- 不做所有鱼种的综合分/平均分。
- 不做多张曲线叠加或矩阵表格。
- 不改水域、气压、溶氧、洪水、影子模型的评分公式。
- 不恢复地图/搜索/GPS。
- 不加后端。

## 5. 方案对比

- **A 排行优先（选）**：7 天卡片显示当天最佳鱼种；详情顶部主钓 + 备选排行；下方详情跟随“查看鱼种”。最直接回答“今天主钓哪种”。
- **B 每鱼种一块**：每个鱼种一张卡；4 种就会很长，不像建议。
- **C 多鱼种矩阵**：对比强，但手机太密，7 天卡片复杂。

B/C 不选。

```text

────────────────────────────────────────
周三 11/25

│ 鲫鱼 82 分 · 极佳                     │

  鳊鱼 78 · 05:00–07:00
  翘嘴 76 · 05:00–07:00
  鳜鱼 72 · 06:00–08:00
```

- 主钓和排行按当天分数从高到低排序。
- 第一名和第二名差 ≤3 分时，主钓下加一句“差距很小，可以都准备”。
- 排行默认前 3，超过 3 个显示“展开全部 4 种”；展开后按分数排。
- 排行里被查看的鱼种高亮；主钓仍是第一名，不因查看别的鱼而改变。
- 日期选择沿用现有 7 天卡片。

## 7. 状态与计算

### 7.1 状态

- `TARGET_SPECIES`：常量 `['crucian','bream','culter','mandarin']`。
- `S.focus`：当前查看鱼种，默认当天主钓。
- `S.sel`：当前选中的日期下标（沿用）。
- `S.outs`：`{ [key]: computeForecast 输出 }`，4 种各一份。
- `S.days`：`bestByDate` 的合并结果，每天含 `top` 和 `ranking`。
- `S.alerts`：`mergeAlerts` 的全局安全提示。
- 每个 `out.shadow`：该鱼种的 v0.6 影子结果；只用于当前查看鱼种的影子行。

### 7.2 recompute

1. 对 `TARGET_SPECIES` 每种调用一次 `computeForecast({ ...opts, species: key })`。
2. 每个结果再算一次 `model:'0.6'` 影子，挂到该结果的 `shadow`。
3. 按日期合并：
   - 每个日期的 `ranking` = 各鱼种该日的 `score/level/windows/day_cap`，按分数降序；同分按 `TARGET_SPECIES` 顺序。
   - `top` = ranking[0]。
   - 7 天卡片用每天的 `top`。
4. 全局安全提示：合并所有鱼种的 `alerts`，按 `日期 + line` 去重（同一天同一条天气警告只显示一次；不同鱼种不重复刷屏）。
5. 如果当前 `S.focus` 不在 `TARGET_SPECIES` 或该日无数据，重置为 `top.key`。
6. 单个鱼种计算失败时跳过该鱼种；4 种全失败才显示天气错误。

### 7.3 日期与查看鱼种

- 点某天：`S.sel = i`，`S.focus = 该天 top.key`，重新渲染详情。
- 点排行里的鱼种：只改 `S.focus`，不重新算天气；下方详情/曲线/影子切换。
- 展开/收起排行：只改本地展开状态，不重新计算。

### 7.4 URL

- `syncUrl` 不再写 `sp`。
- `readUrl` 不再读 `sp`；旧链接里的 `sp=` 忽略。
- `?lat=&lon=&w=&wt=&n=` 保持现状。

### 7.5 纯函数模块

新增 `web/rank.js`，不碰 DOM：

```js
rankDay(outputs, date)       // → [{key, name, day, score, level, level_index, windows, day_cap}] 降序
bestByDate(outputs, dates)   // → [{date, top, ranking}] 给 7 天卡片和详情
mergeAlerts(outputs)         // → 去重后的全局安全提示
```

`outputs` 的形状：`[{ key, name, out }]`，`out` 是 `computeForecast` 的完整输出。

`app.js` 只负责渲染和状态。`tools/test-rank.mjs` 覆盖：排序、同分、缺某天、单鱼种、并列前二 ≤3、4 种全选。

## 8. 边界情况

- **某鱼种当天没有好时段**：显示“没有好时段”，仍按分数排序。
- **当天有雷暴/大风/浪/强降水/低氧**：排序用封顶后的分数，主钓/排行都显示封顶标记；安全提示不隐藏。
- **鱼种输出缺某天**：该鱼种在该天不参与排行；所有鱼种都缺的日期跳过；全部日期都缺则提示没有数据。
- **URL 带 `sp`**：忽略，统一按 4 种排序。
- **手机宽度**：7 天卡片 3 列；排行一行一个；主钓卡不横向滚动。
- **影子分**：跟随当前查看鱼种；主钓排行使用 v0.5，不受影子影响。
- **台钓建议**：style=taiwan 时，非路亚鱼种给粉饵，路亚鱼种给虾饵优先。
- **只选中一种鱼**：UI 不会出现；`rankDay` 仍要能处理单元素输入（测试覆盖）。
